# Background music

Drop MP3 files in this folder using these exact filenames:

| Case | File |
|------|------|
| The "Hoover Eras" Tour Audit | `eras-tour.mp3` |
| Hoover Basketball Arena Audit | `basketball-arena.mp3` |
| Zelda × Minecraft Fest Audit | `zelda-minecraft.mp3` |
| Gaming Club (Budget) | `gaming-club.mp3` |
| Sneaker Design Club (Budget) | `sneaker-club.mp3` |

If a file is missing, the case still works — the browser just silently
fails to load the audio. Each case has a "🔊 Mute" button in the top-right.

## Where to get royalty-free music

Use tracks licensed for public use (NOT the real Taylor Swift, Zelda, or
Minecraft songs — those are copyrighted and would get the page taken down).

- Pixabay Music — https://pixabay.com/music/ (free, no attribution)
- YouTube Audio Library — https://studio.youtube.com (free, download the MP3)
- Incompetech / Kevin MacLeod — https://incompetech.com (CC-BY)
- Free Music Archive — https://freemusicarchive.org

Search suggestions per case:
- eras-tour: "upbeat pop", "sparkle pop", "concert hype"
- basketball-arena: "sports rock", "stadium hype", "arena intro"
- zelda-minecraft: "chiptune adventure", "8-bit fantasy", "retro game loop"
- gaming-club: "lofi chill", "arcade chiptune"
- sneaker-club: "streetwear lofi", "hip-hop instrumental"

## File size tip

Keep each file under ~2 MB so the site loads fast over school wifi. A
30-60 second looping track is plenty — it loops automatically.
