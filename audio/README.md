# Background music

Drop ONE MP3 file in this folder named exactly:

```
background.mp3
```

It plays on every screen and loops. The 🔊 / 🔇 button in the top-right
of every page mutes / unmutes; the choice is remembered (localStorage).

If the file is missing, the page still works — it just stays silent.

## Where to get a royalty-free track

Use a track licensed for public use (NOT real Taylor Swift, Zelda, or
Minecraft songs — those are copyrighted and would get the page taken down).

- Pixabay Music — https://pixabay.com/music/ (free, no attribution)
- YouTube Audio Library — https://studio.youtube.com (free, download MP3)
- Incompetech / Kevin MacLeod — https://incompetech.com (CC-BY)
- Free Music Archive — https://freemusicarchive.org

Search suggestions: "career fair", "upbeat corporate", "kids fun loop",
"happy ukulele", "bright pop instrumental".

## File size tip

Keep it under ~2 MB so the site loads fast on school wifi. A 30-60 second
looping track is plenty — it loops automatically.

## Browser autoplay note

Most phone browsers block sound until the user taps the screen. The
first tap on the page kicks off playback automatically — no extra click
needed.
